## 경기 방식

### 기본 토너먼트

3레인은 1차~3차 라운드, 5레인은 1차~5차 라운드로 운영합니다.  
각 라운드의 결승 진출자를 모아 최종 결승을 진행합니다.

### 1R 포인트전

1차 라운드는 포인트 합산 결선으로 진행하고, 이후 라운드는 토너먼트 방식으로 진행합니다.

- 포인트 1차전: 3점 / 2점 / 1점 / 0점
- 포인트 2차전: 3점 / 2점 / 1점 / 0점
- 포인트 3차전: 5점 / 2점 / 1점 / 0점

### 패자부활 토너먼트

패자부활은 1차/2차/3차 라운드 구조가 아니라 하나의 큰 토너먼트 흐름입니다.  
원하는 시점에 패자부활전을 추가하고, 진출자를 합류시켜 다음 경기를 진행합니다.

## 조 편성 규칙

- 레인 수는 실제 경기장 구조입니다.
- 다음 경기 조 인원은 레인 수와 별도로 선택할 수 있습니다.
- 1명짜리 단독 조는 만들지 않습니다.
- 남는 1명은 다른 조에 합칩니다.
- 한 조의 실제 인원은 레인 수를 넘지 않습니다.
- 부족한 레인은 `빈 레인`으로 표시합니다.
